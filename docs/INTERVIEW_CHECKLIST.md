## Before starting

- [ ] Verify a real AI reply works before the participant arrives.
- [ ] Select Interview demo and the same assignment source used for other participants.
- [ ] Start a new conversation.
- [ ] Explain: “We’re testing the app, not you. The assignments and calendar are fictional. Please say what you’re thinking. You can stop anytime.”
- [ ] Ask permission to take anonymous notes and save the conversation. Ask separately before recording.
- [ ] Ask briefly: “How do you currently decide what to study?”

## Let the student try it

Read one scenario at a time. Do not dictate the exact wording or tell them which buttons to press.

| Done | Scenario to read | Outcome: independent / assisted / failed | Stuck moment, error, or help supplied |
|---|---|---|---|
| [ ] | “You have four hours to study. Ask TaskPilot what to work on.” | | |
| [ ] | “Your plans changed. You only have one hour. Update your request.” | | |
| [ ] | “Find out which assignments are due soon and what you should prioritize.” | | |
| [ ] | Start a new conversation. “Ask for planning help without saying how much time you have.” | | |
| [ ] | “Tell it you now have two hours instead of four.” | | |

If the student hesitates, use a neutral prompt:

- “What are you expecting it to do?”
- “What does that answer mean to you?”
- “What would you do next?”

Do not hide model failures or count assisted completion as independent success. Note if they use a suggested question instead of typing their own.

Optional calendar extension, after the five committed scenarios: “Ask to start after your last commitment.” Record it separately from the original M3 scenarios.

## Wrap up

- [ ] Ask: “Is there anything else you’d like us to know?”
- [ ] Thank the participant.
- [ ] Save the conversation, with permission, before starting a new one.
- [ ] Record one specific surprise: ____________________
- [ ] Record the strongest observed benefit or failure: ____________________
- [ ] Finish the M4 session summary: context, date/format, task, step-by-step behavior, stuck moments, surprise, and reuse conditions.

Use participant codes, not full names, in committed evidence. M3 planned ten participants; M4 requires at least five outside the team. Explain any deviation. This sheet is a blank collection tool, not evidence of completed testing.
